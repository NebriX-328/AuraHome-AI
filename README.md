## 💡 Inspiration

Modern smart home technology is often reactive rather than intuitive—waiting for explicit commands instead of seamlessly orchestrating our daily lives. With the launch of Alexa+ and the Model Context Protocol (MCP), we saw an opportunity to bridge this gap. 

We were inspired to build **AuraHome AI** to transition the smart home experience from rigid trigger-action scripts to a truly proactive, context-aware digital concierge. Our goal was to create an intelligent living companion that anticipates needs, optimizes household routines, and coordinates complex workflows naturally through voice.

---

## 🏗️ Architecture & How It Works

AuraHome AI uses a self-hosted **Model Context Protocol (MCP)** server adhering to the `2025-11-25` specification, leveraging **Streamable HTTP (Server-Sent Events)** for low-latency, dynamic tool execution with Alexa+.
